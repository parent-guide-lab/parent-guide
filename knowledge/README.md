## 入库检查(新文件必过)

任何新知识文件入库走**四件套**(协议见 skill `references/knowledge-index.md` §5,
发布门 `scripts/publish.sh` 自动把关第 1-2 道,第 3-4 道为流程门):

1. **三要素留档**:头部注明 来源 + 入库日期 + 核对方式(哪些经原文核对、
   哪些是转述)——「未核对不入库」;健康类(疫苗/剂量)必须经官方原文核对,
   过期口径以入库日期为复查线索;
2. **引用对账**:`bash skills/parent-guide/scripts/audit-citations.sh knowledge/<file>.md`
   通过——悬空文件引用、无来源医学断言会被拦下;
3. **官方关系标注**:与官方库同主题文件的关系逐条标注(互补/一致/张力+
   以官方为准的理由),冲突处不悄悄站边;
4. **逐断言全审(2026-10-09 起)**:subagent 按标准审计协议对新文件全审
   (每条承重断言,非抽样;协议模板与预算见 `docs/knowledge-audit-sop.md`),
   全部 ✅/处置完并经用户拍板才合并——新内容不欠审计债。

四件全过才入库;任何一件不过,如实报告而不是硬入。存量文件按
`docs/knowledge-audit-LOG.md` 台账轮转深审(逐句级,一年一轮)。
