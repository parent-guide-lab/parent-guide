# 启蒙专题调研 SOP(topic-research)

> 定位:「开一个新启蒙专题」的权威流程——从英语启蒙(R1-R9,
> docs/english-enlightenment-research-2026-10-17.md)与数学启蒙(R1-R4,
> docs/math-enlightenment-research-2026-10-19.md)两轮实战中提炼。
> **过程七步内核在 skill `references/research.md`(SIFT+REA/GRADE+
> Deep Research 三源),本文件管「专题怎么开、轮次怎么排、怎么合入」,
> 不重复内核**。与 knowledge-audit-sop.md(审)、distill-sop.md(蒸馏)
> 并列为三大过程资产。
> 用法:**每个专题单开一个对话**——开场说「按 docs/topic-research-sop.md
> 开 <专题> 启蒙调研」,按 §1 起手;维护者拍板点见各节。

**开场提示词模板**(单开对话直接用):

> 第 1 项,状态改调研中)。先跑 §0 起手检查和 §1 R1 四路,R1 底稿
> §4.2 已有逻辑狗德国官网原文级材料,直接复用。

1. 库内覆盖检查:`grep -ri "<主题关键词>" knowledge/` + BACKLOG.md 有无缺口行

## 1. R1 初始轮(每个专题必跑)

**四路并行 subagent,每路独立七步内核**(英语/数学两专题实测的最优配置,
可按主题裁剪路数):

| 路 | 调研问题 | 产出 |
|---|---|---|
| A 领域定形线 | 学术名称与子域构成(中/英);与其他相邻领域的边界(如数学认知 vs 思维训练);官方文件里的位置(《指南》/课标) | 领域定义+边界判定(交叉/包含/独立) |
| B 发展科学线 | 发展轨迹(几岁会什么);预测力(相关非因果如实);家庭干预证据分级表(每项:设计+复现状态+家长操作形态) | 证据层 |
| C 官方口径线 | 中国官方优先(《3-6 指南》对应领域目标原文/政策文件);国际补充(EYFS/CDC/权威机构立场);0-3 有无要求 | 官方口径层+中外对照 |
| D 需求侧线 | 家长高频问题 Top 8-15(知乎/社区,热度信号);产品市场初扫(品类图谱,线索级);机构 FAQ 覆盖对照 | 迷思表素材+产品层线索 |

**每路纪律**:预算 ≤12-14 检索+≤10 抓取(超限如实记录);调研问题清单
先行禁止裸搜;抓取 fallback 阶梯(WebFetch→webReader→curl→「未获取原文」);
溯源分级(原文级/摘要级/机构级/转述级标日期/标题级;软广嫌疑标不可用);
矛盾解决或并陈;**subagent prompt 不给预期答案、复核任务不给预期数字**
(确认偏误判例)。

**汇总与交付**:主会话做矛盾处理(路间冲突以更高分级来源为准,定不了
就并陈)→ 底稿八节(research.md §3 模板:起因/方法/一句话结论/论证/矛盾/
拍板点/来源清单/已查明待补研)→ commit 调研轮(commit message 含完整
轮次叙事)→ 向用户呈现「结论先行+拟入库方案+拍板点(A/B/C 附推荐)」。

## 3. 入库合入流程(每轮拍板后,顺序固定)

1. 底稿 append(cat/>> 或 Edit,带 URL+分级+销账记录:~~项~~→已查明 §x)
2. 用户拍板(「A」「A+B」等)→ 改 `knowledge/<topic>.md`:
   新增节+交叉引用(§ 指向句)+头部核对 blockquote 追记本轮分级
3. **新文件四件套**(官方闭集双侧登记):check-knowledge.sh(存在性循环+
   三要素循环+closed set+OFFICIAL python 集四处)、publish.sh 白名单、
   build-site.py TOPICS(**组=必填,组连续性断言**)、build-site.sh 渲染行
4. 速查与路由:knowledge-index.md §2 速查行+§4 路由行+SKILL.md 路由表行
5. 台账 docs/knowledge-audit-LOG.md 追行(模式与统计/遗留/下次深审档期)
6. knowledge/README.md 现状表行
7. 门禁三绿:audit-citations.sh knowledge/<topic>.md + tests/check-knowledge.sh
   + scripts/build-site.sh(顺序:先 build 再 check,check 查 knowledge.json)
8. 用户级同步:改过 skills/ 内文件后 cp 到 ~/.zcode/skills/parent-guide/
   (被拦改 Edit),diff -r 验收 SYNC-OK
9. commit(轮次叙事)→ publish.sh --push → 记忆更新
   (parent-guide-latest-decisions 追加轮次记录)

## 4. 纪律清单(判例精华,违反=返工)

- **无官方口径不编造**:「买多少」「每天几页」无机构数字就写纪律与
  社区流传标注,不造数字(英语 R6「买 N 册」/数学 R4「每天 5-10 页」)。
- **时点快照声明**:价格/渠道/在架类内容=时点快照+「购买前自行核对」
  (english.md §3 先例);复审档期=渠道价格优先。
- **形态-证据匹配检查**:产品形态与研究干预形态对不上要点名(市售蛇棋
  1-100 vs 证据 1-10;数学 R4 核心发现)。
- **逻辑方向自查**:充分/必要、更优/更差、样本地、年龄组挂靠——推断
  翻译环节最易翻转(英语 R4 九类实错)。
- **两轮制**:非原文级判断只标「待核」不触发修改;审计员「未复现」≠错,
  先查既往原文级归档(英语 R9 裁定技巧)。
- **外部推降档**:美国/欧洲样本向中国家庭、学龄样本向学前——逐条标注。
- **相关≠因果**;孤立研究≠共识;meta 的调节子样本限制如实带。
- **并发纪律**:多会话并行时 commit 前 git log;精确 add 本批文件不 add -A;
  publish 失败=公开仓 reset --hard+clean 后重跑。
- **B 路备用方案**:subagent 被 provider 拦(内容过滤/限额)→主会话快调研
  (≤5 检索+3 抓取)补缺口,如实记录(数学 R2 先例)。

## 5. 底稿与正文的结构惯例

- 底稿命名:`docs/<topic>-enlightenment-research-<YYYY-MM-DD>.md`,八节起,
  后续轮次按 §N 追加(R2 从 §9 起),拍板结果与补调研记录追记当轮尾部。
- 正文 `knowledge/<topic>.md`:头部溯源 blockquote(逐轮追记核对分级)→
  §0 一句话结论+纪律 → §1 迷思表 → §2 证据层 →(§2.x 深化节)→ §3 官方
  口径 →(§3.5 产品层时点快照)→ §4 红旗(T2)→ §5 来源与时效(指向底稿
  各轮 §)。
- 分工句写进头部(与 milestones/screen/activities 等相邻文件的边界)。
