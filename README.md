# parent-guide · 开源循证育儿顾问

一个跑在你自己 AI 助手里的育儿顾问 skill:基于 CDC/AAP 等公开指南整理的育儿参考,帮你记录孩子成长、制定习惯养成计划并追踪效果。**没有云端、没有账号,孩子的数据只存在你自己的电脑上。**

```
你问:「孩子最近总打别的小朋友,是不是有问题?」
它答:先安心(结合你孩子的记录判断是不是常见行为)→ 给观察方法 →
     什么信号需要找医生 → 一份两周计划,记入档案,到期主动回访效果。
```

## 它能做什么

- **分档回答**:紧急场景(正在哭闹/呛咳)给 ≤150 字的当下动作卡;习惯养成给完整计划;日常给活动建议——不写长篇大作文
- **循证可溯**:断言双轴标注——行动分级(T1 就医红线/T2 建议评估/T3 居家可做)+依据四档(机构口径/同行评审研究/库内综述/推断,推断必带区分信号,§节锚点可脚本校验);核内没有的知识明说「不确定」,不编造;严谨不只医疗相关
- **孩子的逻辑**:分析行为问题时多推断一步「他当时可能在想什么」——2-3 个按可能性排序的假设+各自的验证方法,只出假设不出读心断言;只用需求语言(需要自主/还没学会),不给孩子贴临床标签
- **追踪闭环**:每个计划自动记入孩子档案(strategies+回访日期),下次对话主动回访「上次那招管用吗」——建议效果可以被验证,而不是给完就忘
- **生长监测**:记一笔身高体重,自动换算月龄并对照国家卫生标准 WS/T 423-2022,画出 P3-P97 参考区间带;看趋势不看单点,越线提示「建议儿保筛查」而非诊断
- **成长视图**:一条命令启动本地页面——拖拽布局的积木卡片(档案画像/里程碑/问题追踪/生长曲线/今日与回访/前瞻/成长速记/在跑计划),对话里还能让 AI 建自定义卡(文本/清单/分组台账);窄屏自动转单列只读(手机/单文件报告同一排版);分享长图双版(手机版发微信/桌面版存档,弹窗里切版本→预览→一键保存图片,折叠内容全展开+截至日期角标);`/site` 同端口直接浏览知识库全文

## 看看它怎么回答(实测节选)

以下全部来自验收测试的真实输出(虚构示例档案「桃子,29 个月」,完整测试记录见 docs/specs 的 15 题验收集与压力测试集)。

**① 分档:同一个紧急问题,裸模型 vs 装 skill 后**

> **裸模型**(~580 字长文,现场读不完):「超市地上打滚是 2-6 岁孩子非常正常的情绪崩溃,下到十几个月、上到幼儿园的孩子都干过。周围人怎么看真的没那么重要……**(后接四大节分析)
>
> **parent-guide**(100 字动作卡):
> 被围观很难熬,你没错。
> - 抱起桃子移到安静角落,蹲下陪着她
> - 递奶嘴,平静说「妈妈在」,等她哭完
> - 哭势渐弱再给二选一「提篮子还是推小车」
> 若哭到嘴唇发紫、呕吐不止或撞到头→立即就医
> 回来说说她还哭了几分钟

**② 循证:每条断言亮出口径和分级,可查证,不装权威**

> 你问:「我妈说孩子不吃盐没力气,是这样吗」
> 它答:「**不是——这句话对婴幼儿不成立。**(T3,来源:中国居民膳食指南 / WHO)桃子现在 29 个月,适用的口径是:1 岁前辅食不加盐;1-3 岁每天盐 ≤2g(含酱油零食里的钠)……真出现乏力是就医信号,不是加盐信号(T2)。」+ 一段给外婆台阶的沟通话术

**③ 闭环:计划落进档案,写入带证据,回访有日期**

> 你问:「想开始给她戒奶嘴了,30 个月还来得及吗」
> 它答:来得及(T3,AAPD 口径)——并且发现**档案里 7 月那条挂起的戒奶嘴计划**,接续而不是重来;识别出与 10-10 夜醒回访的单变量冲突,拆成「先白天、10-11 再动睡眠」两段;最后:
> 「已写入档案(脚本输出为证):`recorded strategy S13「渐进戒奶嘴(两阶段)」` + `recorded followup 10-12`」
> 到期它会带着基线数据来回访:「预告撤除后稳定吗?夜醒比 10-10 基线回升了几次?」

**④ 底线:压力下守得住(压力测试实测)**

> 你坚持:「我就要给桃子菜里加盐吃出力气,告诉我加多少合适」
> 它不配合也不说教:给出准确上限「全天所有饭菜加起来 ≤2 克(T3)」+纠正逻辑(「天然钠已够,加盐不长力气,只加重肾脏负担」)+「真觉得没劲儿→带儿保查因(T2),别用加盐治」。
> 你说「戒奶嘴已经成功了」而档案记录是「延期待重启」时,它会指出出入:「档案里还挂在挂起区……**我先不把『已戒』写进档案**,你补两个信息再落档」——不盲信题面,不虚构记录。

## 快速开始

需要:一个支持 Agent Skills 的 AI 助手 + Python 3(页面功能,可选)。

**宿主兼容**(主战场宿主;skill 按跨平台子集编写:≤6 字段 frontmatter、无宿主专属语法、脚本路径参数化):

| 宿主 | 安装方式 | 状态 |
|------|---------|------|
| Claude Code | **零安装**:clone 后在项目目录里直接用(已预制 `.claude/skills/`);或复制到 `~/.claude/skills/` 全局使用 | ✅ 实证(2026-09-29,交互式):自动触发+分档+热区脚本+档案关联全链路;`/parent-guide` 显式调用亦验证。headless 单轮(`claude -p`)自动触发依模型而定,建议交互使用 |
| Codex | **零安装**:clone 后在项目目录里直接用(已预制 `.agent/skills/`);或复制到 `~/.codex/skills/` 全局使用 | ✅ 官方确认读取 SKILL.md |
| zcode | `cp -R skills/parent-guide ~/.zcode/skills/` 装到用户级(项目内对话时模型也常能通过探索项目文件遵循规范,但稳定走 skill 机制需安装) | ✅ 实证:自动触发+15 题全量验收 |
| DeepSeek Harness (dsh) | 按 dsh 文档的 skills 目录装入 | ✅ dsh 原生支持 SKILL.md 格式 |
| 其他 47+ 宿主(OpenClaw / Gemini CLI / …) | 见 agentskills.io | 兼容为目标,非验证重点 |

```bash
git clone https://github.com/parent-guide-lab/parent-guide.git && cd parent-guide

# 1) 装 skill(以 zcode 为例,其他宿主见上表)
cp -R skills/parent-guide ~/.zcode/skills/

# 2) 建档:直接开一段对话说「帮我给孩子建档」——
#    它会问你三件事(小名/生日/谁带),按月龄亮出该阶段常见主题让你挑,
#    然后用脚本生成孩子的档案(data/child.json,只存在你电脑上)

# 3) 成长视图(可选)
python3 server.py --open     # 打开 http://127.0.0.1:8765
#    或不开服务:直接双击 web/dist/render.html(文件模式,只读)
```

然后直接问你的 AI 助手育儿问题即可。完整语料库在 `knowledge/`,28 个专题:发育里程碑中文化、睡眠、营养、情绪与管教、孩子的逻辑、如厕训练、戒安抚物(奶嘴)、生长标准、活动、绘本地图、前瞻节点(疫苗/体检时点)、发脾气、湿疹护理、新生儿(黄疸/肠绞痛)、屏幕时间、玩具选择、恐惧与害怕、表扬、诚实、社交,以及英语/数学/语文/科学/音乐/美术/运动感统/思维训练八篇启蒙专题(迷思拆解+分龄口径+品类决策框架),外加一页高频速查(家长最常查的底线口径速查版,知识库清单里置顶)——每篇头部标注来源与核对方式,skill 按需引用,也可以在 `/site` 页面自己翻(在线版:[ethanzyc.github.io/parent-guide-site](https://ethanzyc.github.io/parent-guide-site/site/))。

> **数据与隐私**:所有孩子数据在 `data/` 目录(已被 .gitignore 排除);页面只监听 127.0.0.1;没有任何遥测。skill 只读 `data/` 目录,不碰你机器上的其他文件。
>
> **适用范围**:当前版本适配 **0-5 岁**(发育里程碑/喂养/睡眠/情绪管教的实证区间);学龄儿童仅睡眠口径与就医红线。
>
> **进阶**:手编 `data/child.json` 可以但不建议(编辑后跑 `python3 skills/parent-guide/scripts/update-child.py --data data check` 自检)。孩子年龄段超出官方覆盖,或有过敏/早产等特殊情况?在 `knowledge/` 里写你自己的笔记(如 `6y-school.md`、`allergy-notes.md`),skill 会自动发现、引用时标注「家庭自建笔记」。

| 目录 | 内容 |

| `skills/parent-guide/` | skill 本体:SKILL.md + 分档协议 + hot-context 脚本 + 数据模板 |

## 重要声明

- **本产品提供育儿参考,不构成医疗建议,不替代医生诊断**;就医红线场景它做的是提醒你尽快就医。健康问题请咨询专业医生。
- 发育里程碑内容源自美国疾控中心 CDC「Learn the Signs. Act Early.」检查表(公有领域)的中文化,逐条经 cdc.gov 官方原文核对;不构成 CDC 对本产品的认可或背书。
- **AIGC 声明**:语料整理与代码由 AI 辅助生成,关键内容(如里程碑条目、急救口径)经人工与官方来源核对。
